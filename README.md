# 💼 AI Career Navigator

## 🚀 Live Demo

👉 [Launch AI Career Navigator](https://task3shrutijadhav-ejyooh9obevk8srfbflsc8.streamlit.app/)

An AI-powered personalized job recommendation system that matches users with relevant career opportunities based on their skills, experience, industry, location, and salary preferences.

---

## 🧠 Recommendation Model

The system uses:

- TF-IDF
- Cosine Similarity
- Skill Matching
- Industry Matching
- Experience Matching
- Location Matching
- Salary Preference

### Recommendation Score

**Final Score =**

- 50% Skill Similarity
- 20% Industry Match
- 15% Experience Match
- 10% Location Match
- 5% Salary Score
